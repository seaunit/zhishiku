# 识海环境变量前缀迁移

日期：2026-10-22

## 规则

- 识海专用环境变量的正式名称为 `SHIHAI_*`。
- Waffo 变量使用 `SHIHAI_WAFFO_*`。
- 旧名称仅作为迁移期兼容别名。
- 新名非空时使用新名；新名为空时回退旧名。
- 新旧名称同时存在时必须写入相同值；值不同时 Spring、Waffo 桥接和部署脚本失败关闭。
- 部署脚本同时写入同值旧别名，保证回滚到上一 release 后仍可启动。
- 操作系统、Spring 和第三方工具自身变量不强制改名，例如 `JAVA_HOME`、`PATH`、
  `PLAYWRIGHT_BROWSERS_PATH`。

## 覆盖范围

- 数据库、端口、Cookie、SMTP、注册和账号初始化。
- DeepSeek AI、Search、Fetch、OCR、浏览器 worker 和文档导入限制。
- Waffo 商户、店铺、私钥、商品映射、环境、币种和成功回跳。
- 点数计费、内部桥接密钥、Webhook、退款和管理员邮箱。
- 部署脚本控制变量和测试/性能测试专用变量。

## 验证

- Spring 新名绑定、旧名回退、空新值回退、同值兼容和异值失败测试。
- `spring.factories` 注册检查，确保冲突检查在应用启动前执行。
- Waffo 新名优先、旧名兼容、异值失败和非 CNY 币种拒绝测试。
- 部署脚本对全部 `SHIHAI_*` 自动推导旧别名，完整扫描环境文件。
- provision 保留未托管的现有配置，只更新受管变量。
- 双写、冲突检测、环境文件保留、Bash 语法和部署依赖自检。

## 残余风险

- 本机 Docker 不可用，Testcontainers PostgreSQL 用例未实际执行。
- 本机未安装 `shellcheck`，部署脚本只执行 `bash -n` 和黑盒函数检查。
- 旧别名至少保留一个稳定发布周期；确认回滚目标均已迁移后才能移除。
