# 八位密码下限验收

**日期**：2026-10-22

## 变更结果

- 注册、登录和初始化账号的密码最小长度统一为 8 位。
- 密码最大长度保持 256 位。
- 前端注册页和登录页使用 `minlength=8`、`maxlength=256`。
- 后端登录、注册、初始化和账号创建服务独立复验长度。
- 中文和英文提示均显示至少 8 个字符。
- OpenAPI 中登录、注册和初始化密码字段统一为 `minLength: 8`。

## 边界

| 输入 | 预期 |
|------|------|
| 7 位密码 | 拒绝创建或登录 |
| 8 位密码 | 允许 |
| 256 位密码 | 允许 |
| 257 位密码 | 拒绝 |

## 验证

- `OwnerServiceTest`：8 位创建成功，7 位被拒绝。
- 注册控制器：8 位密码通过请求业务校验。
- 登录 E2E：8 位密码可提交。
- 注册 E2E：密码输入框下限为 8，8 位密码完成注册流程。
- 前端 lint、typecheck、Vitest、生产构建和全量 E2E 通过。
