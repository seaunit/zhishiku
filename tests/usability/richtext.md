# 富文本编辑与图片可用性研究协议

## 状态

**未执行。** 本文件是 10 人研究协议和空白记录模板，不包含参与者数据，也不得把空白记录描述为
实验结果。

## 研究目标

1. 验证 SC-001：至少 9/10 名参与者能在 3 分钟内创建一条含标题、列表、链接和一张内嵌图片的
   知识。
2. 验证 SC-014：至少 9/10 名参与者能为图片填写说明或替代文本，并理解其用途。
3. 观察手机工具栏、更多菜单、表格和图片错误恢复中的阻断问题。

## 参与者

- 共 10 名，均为成年知识工作者或经常收藏资料的个人用户。
- 至少 4 名主要使用手机完成资料整理。
- 至少 3 名每周使用富文本编辑器或文档工具。
- 不招募本项目开发、测试、产品或直接利益相关者。
- 不收集不必要的姓名、雇主、邮箱或健康信息；参与者使用编号 P01–P10。

## 设备与材料

- 桌面 Chromium 和一台真实手机，覆盖 320–430 CSS 像素。
- 合法 JPG/PNG 测试图和必须拒绝的 SVG。
- 含标题、列表、链接、表格和远程图片的粘贴材料。
- 计时器、同意书、观察表和匿名任务产物。

## 流程

| 阶段 | 时长 | 内容 |
| --- | ---: | --- |
| 介绍与同意 | 5 分钟 | 说明自愿参与、录制选项和退出权利 |
| 背景问卷 | 3 分钟 | 设备、知识整理频率和编辑器经验 |
| 任务 A | 最多 3 分钟 | 新建含标题、列表、链接和一张图的图文知识 |
| 任务 B | 最多 3 分钟 | 为图片填写说明或替代文本 |
| 任务 C | 最多 3 分钟 | 粘贴网页内容，移除不允许的图片并保存 |
| 回溯访谈 | 8 分钟 | 询问理解、犹豫点和恢复方式 |

## 任务脚本

### 任务 A

> 请把这份资料保存成一条便于以后查找的图文知识。需要包含一个标题、一组列表、一个可用链接
> 和一张图片。准备好后开始，完成时告诉我。

观察：是否找到新建入口；是否找到格式控件；是否成功插入图片；是否在 3 分钟内保存。

### 任务 B

> 请让以后看不到图片的人也能理解这张图片表达了什么，并说明你会把这句话放在哪里。

观察：是否找到说明/替代文本；是否区分两者；装饰性图片是否理解。

### 任务 C

> 请把这段网页内容保存进知识库。可以保留有用文字，但页面里的不安全或无法导入的图片不应
> 被自动下载或保存。

观察：是否识别图片降级；是否使用纯文本回退；是否有数据丢失。
