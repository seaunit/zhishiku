# 功能规格说明：截图 OCR 与 AI 拆分导入

**功能分支**：`008-screenshot-ai-import`

**创建日期**：2026-10-22

**状态**：P0/P1 代码已实现；生产受 002 点数门禁与部署验收阻塞

**输入**：用户要求截图知识不保存截图，而是解析截图内容并拆分整理到知识库。

## 范围与定位

本功能遵守 [009 AI 辅助采集统一规则](../009-ai-assisted-capture/spec.md)：剪贴板截图是非
手动采集入口，只能在 OCR、脱敏和 AI 整理成功后创建文字知识。

“截图”入口只接受用户从剪贴板主动粘贴的 PNG 或 JPEG 图片。系统在请求内验证图片、执行 OCR，
再把识别文字脱敏并交给 AI 拆分为一条或多条知识。原始截图只作为临时 OCR 输入，不长期保存，
不进入知识正文，也不创建只有图片附件的知识。

截图入口不得显示文件选择、拖拽、相册或相机上传控件。WebP/HEIC、复杂表格、公式恢复和
多图合并属于 P2。

生产门禁：截图 OCR 和 AI 拆分属于付费能力。002 报价、预留、结算和释放未接入前，生产必须
返回 `402 AI_BILLING_REQUIRED`。

## 用户场景与测试（必需）

### 用户故事 1 - 粘贴截图并拆成知识（优先级：P0）

用户复制一张含清晰文字的截图，粘贴到截图入口，系统识别并拆分知识。

**为何设置此优先级**：直接解决“截图知识保存截图附件”的错误产品语义。

**独立测试**：粘贴一张包含两个可区分段落的 PNG，确认没有图片上传或附件写入，OCR 后创建
两条正文可搜索的截图知识。

**验收场景**：

1. **假设**用户复制 PNG 或 JPEG 截图，**当**在截图入口粘贴，**则**页面显示预览和外部 AI 同意。
2. **假设**用户勾选同意并提交，**当**OCR 和 AI 成功，**则**创建一条或多条知识。
3. **假设**知识创建成功，**当**打开详情，**则**正文是可检索文字，来源类型为 `screenshot`，
   不显示原始截图附件。
4. **假设**用户备注不为空，**当**知识创建成功，**则**备注附加到每条知识。
5. **假设**用户未粘贴截图或未勾选同意，**当**查看提交按钮，**则**按钮禁用。

---

### 用户故事 2 - 图片安全和失败关闭（优先级：P1）

系统拒绝空图、损坏图片、超限图片、秘密图片和无文字截图，不创建部分知识。

**为何设置此优先级**：截图可能包含密码、Token 和私密信息，必须在 OCR 和外部 AI 前完成
图片安全检查。

**独立测试**：粘贴损坏 PNG、超过 25 MiB 图片、1×1 空白图、疑似密钥图片和 OCR 失败，
确认不调用 AI 或知识创建，并显示具体错误。

**验收场景**：

1. **假设**图片不是 PNG/JPEG、动画图片或像素超限，**当**提交，**则**返回
   `SCREENSHOT_IMAGE_INVALID/SCREENSHOT_UNSUPPORTED`。
2. **假设**图片原始字节检测到高置信密钥，**当**提交，**则**整张截图拒绝，不进行 OCR。
3. **假设** OCR 无足够文字，**当**处理完成，**则**返回 `SCREENSHOT_NO_TEXT`。
4. **假设**识别文字超过 30,000 字符，**当**处理完成，**则**返回 `SCREENSHOT_TOO_LONG`。
5. **假设** AI 失败或返回空结果，**当**整理失败，**则**不创建知识。

### 用户故事 3 - 移动端与生产验收（优先级：P1）

用户在手机剪切板中复制截图后可以完成粘贴、同意和提交。

**独立测试**：390、320 和 430 CSS 像素下粘贴截图，滚动到底部时主按钮位于固定导航上方。

**验收场景**：

1. **假设**用户使用 320–430 像素手机，**当**粘贴截图，**则**预览、同意和备注无横向溢出。
2. **假设**截图入口打开，**当**查找上传控件，**则**文件输入、相册和相机控件数量为 0。
3. **假设**部署环境缺少 Tesseract 中文语言包，**当**启动部署预检，**则**失败并保留上一版本。

### 边界情况

- 仅 PNG/JPEG；HEIC/WebP 暂按不支持处理。
- 单图 25 MiB、8192 像素单边、4000 万总像素。
- OCR 输出上限 30,000 字符，少于 30 个字母数字字符视为无文字。
- 图片只写临时文件用于 Tesseract；请求结束立即删除，删除失败时注册进程退出清理。
- OCR 文本在发送 AI 前进行密钥、Token、密码、认证头和私钥脱敏。
- 原始截图、OCR 文本和 AI 原始响应不得写日志。

## 需求（必需）

- **FR-001**：截图入口只接受剪贴板图片，不显示文件选择、拖拽、相册或相机控件。
- **FR-002**：系统必须接受 PNG/JPEG，并在 OCR 前校验文件大小、尺寸和像素。
- **FR-003**：图片必须通过现有 `ImageInspector` 格式、尺寸、像素和明显嵌入字节签名检查；
  截图像素中的可视密钥主要由 OCR 后文本脱敏处理，检测到高置信秘密时替换后再外发。
- **FR-004**：系统必须对截图执行 `chi_sim+eng` OCR，且不把截图直接发送给 AI。
- **FR-005**：外部 AI 调用前必须取得用户明确同意。
- **FR-006**：OCR 文本必须经过 `AiTextSecretRedactor` 后再发送 AI。
- **FR-007**：AI 必须创建 1–20 条知识，每条标题、正文、摘要、分类和标签完整。
- **FR-008**：知识来源必须为 `screenshot`，处理状态为 `succeeded`。
- **FR-009**：原始截图不得长期保存或作为来源附件显示。
- **FR-010**：OCR、AI 或入库失败时不得创建部分知识。
- **FR-011**：截图入口不得调用 rich-text 图片上传端点。
- **FR-012**：中文和英文必须覆盖同意、无文字、超限、不安全、失败和不可用状态。
- **FR-013**：桌面、平板和 320–430 CSS 像素移动端必须可完成流程。
- **FR-014**：生产未接入 002 点数门禁时不得调用 DeepSeek。

## 成功标准（必需）

- **SC-001**：100 次成功截图导入中，创建图片附件知识次数为 0。
- **SC-002**：100 次成功截图导入中，正文非空且可检索比例不低于 95%。
- **SC-003**：多主题截图样本中，至少 90% 生成两条或以上知识。
- **SC-004**：截图来源、采集时间和 `succeeded` 状态保留率为 100%。
- **SC-005**：不安全和失败样本中，部分知识写入次数为 0。
- **SC-006**：密钥样本外发前替换率为 100%。
- **SC-007**：320、390、430 像素下控件溢出和主按钮遮挡次数为 0。

## 假设

- 用户粘贴的是自己有权处理的截图。
- 系统剪切板 API 在目标浏览器可用；不可用时提示用户检查浏览器权限。
- 分类和标签继续暂存于知识备注，后续迁移到独立关系表。
- 原始截图不保留；用户如需重新识别必须重新粘贴。
