## P0 门禁

- [ ] 三档识海 SKU 与 Waffo 测试商品一一对应，未复用拾题商品
- [ ] Spring Boot 订单、批次、账本和幂等事务通过 Testcontainers
- [ ] Node 桥接只处理 Waffo SDK、验签和查询，不连接业务数据库
- [ ] 可靠通知或查询后 400 点只到账一次
- [ ] 组合报价、预留、成功结算和失败释放通过并发测试
- [ ] 余量不足时内容仍保存，付费 AI 不启动
- [ ] Node/Java 内部鉴权、超时和重试契约通过
- [ ] 日志、截图、数据库和证据不含私钥、签名或完整支付载荷
- [ ] 拾题原路由、认证、Cookie、证书和支付 sidecar 基线不变

- [ ] Waffo 生产环境使用独立识海商品、地址、订单和账本

- [ ] 通知缺失时可在 10 分钟内主动对账
- [ ] 中文默认、英文完整，价格、点数、扣费和退款事实一致
- [ ] Taste 在 1440/768/390/360 通过
- [ ] GitHub 固定 ref 一键部署、失败关闭和回滚可复现
- [ ] 单位经济性满足可变成本不超过收入 50%、目标毛利不低于 60%
