## P0 执行门禁

- [ ] 三档识海 SKU 与 Waffo 测试商品一一对应，未复用拾题商品
- [ ] 测试订单可在返回页保持“确认中”，且可靠通知/查询后只到账一次
- [ ] 重复、乱序、伪造、金额不符和测试/生产混淆均不能错误加点
- [ ] 100 组并发扣费无负余额、无重复结算和超报价扣费
- [ ] 六类 AI 能力均受报价、确认、预留和成功步骤结算保护
- [ ] 失败、取消、空结果、超时和迟到结果均不重复扣费
- [ ] 自动整理扣点默认关闭，单次/每日上限和余额不足降级生效
- [ ] 余额不足时文字、URL、文档和截图均不丢失
- [ ] 日志、截图、数据库和证据不存在私钥、签名或完整支付载荷
- [ ] 拾题原有路由、认证、Cookie、证书和支付 sidecar 基线不变

## P1 公开销售门禁

- [ ] Waffo 生产环境使用独立识海商品、地址、订单和账本
- [ ] 全额退款只回收原订单批次剩余点数，部分退款进入人工复核
- [ ] 退款与预留竞态、支付与退款乱序、查询冲突均不产生负余额或重复事实
- [ ] 通知缺失时可在 10 分钟内主动对账，失败可重试并进入异常
- [ ] 财务汇总可核对金额、点数、退款和未回收部分
- [ ] 订单、账本、事件和退款至少保留 24 个月且不被知识删除级联
- [ ] 中文默认、英文完整，价格/点数/交易状态事实一致
- [ ] Taste 在 1440、768 和 390 px 通过，文字和控件无溢出
- [ ] GitHub 固定 ref 一键部署、失败关闭和回滚证据可复现
- [ ] 单位经济性满足每套餐可变成本不超过收入 50%、整体目标毛利不低于 60%

## 证据目录

建议证据路径：

```text
artifacts/billing/
├── contracts/
├── events/
├── economics/
├── screenshots/
├── security/
├── load/
├── deployment/
├── recovery/
└── acceptance/
```

每项证据至少记录：

- 测试命令、测试环境和执行日期。
- 目标提交 SHA、夹具版本和随机种子。
- 精确通过/失败计数。
- 关联 FR/SC、任务 ID 和测试文件。
- 脱敏后的余额、订单状态、退款与零影响摘要。
- 未覆盖项、残余风险和回滚方式。

## 评审责任

- 产品子智能体：批准新台价格、点率、体验额度、自动扣点默认值和退款政策。

- 测试子智能体：从用户入口独立执行，验证不依赖开发自测声明。
- 任一 P0/P1 门禁失败时，不得勾选公开销售，也不得启用生产收费。
