# 快速验证：账户菜单与个人资料

**功能**：`005-account-profile`

## 前置条件

- Spring Boot、PostgreSQL 和 Vue 开发环境已启动。
- Flyway 已应用 `V0007__account_profile.sql`。
- 至少存在两个可登录账号，用于隔离检查。

## 自动化命令

```powershell
cd backend
./mvnw.cmd -pl kb-app -am test

cd ../frontend/kb-web
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright test e2e/app.spec.ts
```

## 场景 1：头像菜单

1. 登录并点击顶部头像。
2. 确认页面仍保持登录，菜单显示当前显示名称和邮箱。
3. 确认菜单包含“个人资料”和“退出登录”。
4. 点击外部和按 `Esc`，确认菜单关闭且焦点回到头像。
5. 使用键盘 `Enter` 和空格重复检查。

## 场景 2：编辑显示名称

1. 从账户菜单进入“个人资料”。
2. 确认邮箱只读，头像预览使用名称首字。
3. 输入新的合法显示名称并保存。
4. 确认成功提示、顶部头像和菜单立即更新。
5. 刷新页面和重新登录，确认名称保持。
6. 测试空名称、41 个字符、换行和 `<script>`，确认均被拒绝。

## 场景 3：退出确认

1. 从账户菜单点击“退出登录”。
2. 点击取消，确认仍可访问当前资料和受保护页面。
3. 再次打开并确认退出。
4. 确认进入登录页，向后导航不能继续读取资料。

## 场景 4：多账号与移动端

1. 账号 A 登录时尝试提交账号 B 资料，确认无法越权。
2. 退出后登录账号 B，确认不显示账号 A 的名称或菜单缓存。
3. 在 320、390、430px、平板和桌面检查菜单与资料页。
4. 使用 Taste app-screen 检查 1440/768/390，修复所有 `FAIL`。

## 预期结果

- 头像点击不退出。
- 资料保存和会话状态同步。
- 退出只有在明确确认后才发生。
- 中英文、键盘、移动端和多账号隔离均通过。
