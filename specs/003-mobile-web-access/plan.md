## 摘要

在 Vue 3 前端和 Spring Boot API 架构下，保证识海在 320–430px 手机、平板和桌面浏览器中
完成录入、搜索、阅读、编辑、附件、AI 授权、计费确认、Waffo 跳转返回和回收站操作。
移动适配不得改变桌面业务规则，也不得建立移动专属数据。

## 技术背景

- 前端：Vue 3、TypeScript、Vite、Vue Router、Pinia、TanStack Vue Query、vue-i18n、
  Reka UI、Tiptap Vue 3。
- 后端：Spring Boot API、Spring Security Session + CSRF。
- 验收：Vitest、Vue Test Utils、Playwright、axe-core、Taste。
- 设备矩阵：1440、768、430、390、360、320px、手机横屏、200% 字体和安全区。

## 架构决策

1. **一个 Vue 响应式应用，不建立移动专属页面或数据。**
   路由和 API 与桌面一致，通过 CSS 容器、触控目标和渐进布局适配。

2. **移动导航采用底部导航或抽屉。**
   宽度小于 840px 时侧栏折叠；主要操作保持一屏可达，避免缩小桌面侧栏。

3. **富文本和计费使用同一组件状态。**
   移动工具栏、报价确认和 Waffo 返回不得复制业务逻辑或改变价格。

4. **安全区与键盘是一等约束。**
   `viewport-fit=cover`，底部导航、Toast、编辑器工具栏和提交操作计入
   `env(safe-area-inset-*)`。

5. **生产形态由 Nginx 验证。**
   E2E 必须覆盖 Vue 构建产物、SPA fallback、`/kb/api` 代理、Cookie Path 和 CSRF。

6. **知识库列表搜索与批量删除使用响应式单一交互模型。**
   桌面和平板保留表头三态全选，手机将全选入口放在筛选行下方；每行复选框与删除按钮固定 44px
   触控槽。搜索、来源筛选、分页刷新和删除成功都会清空选择，批量操作栏位于列表上方并使用
   安全区感知的确认对话框。移动端不复制业务规则，只改变控件排列和显示密度。

## 验证矩阵

- 1440px 桌面。
- 768px 平板。
- 430、390、360、320px 手机。
- 手机横屏 844×390 或等效。
- 200% 字体。
- 软键盘打开、关闭和焦点恢复。
- 底部安全区。
- 中文和英文。

## 实施顺序

1. 响应式外壳、底部导航和安全区。
2. 搜索、知识库、详情和表单移动布局。
3. 富文本工具栏、图片和错误状态。
4. 计费确认、Waffo 返回和弱网恢复。
5. 知识库列表搜索、单条/批量删除、三态选择和安全区确认框。
6. 无障碍、双语、Taste 和 Nginx 生产形态验收。

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 软键盘遮挡保存按钮 | VisualViewport、安全区和真实 Playwright 检查 |
| 移动工具栏不可发现 | 44px、更多菜单和固定图片/链接入口 |
| 底部导航遮住内容 | 动态 padding + safe-area |
| SPA fallback 失败 | Nginx staging E2E |
| Waffo 返回上下文丢失 | 非敏感 return context、订单查询和恢复 |
| 桌面回归 | 同一路由和业务规则下做 1440/768 对比 |
